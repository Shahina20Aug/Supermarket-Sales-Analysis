Supermarket Sales Analysis – Excel Project
📌 Project Overview

This project focuses on analyzing supermarket sales data using Microsoft Excel. The objective is to understand sales performance, customer purchasing behavior, product performance, and overall business trends through data analysis and visualization.

The project uses Excel features such as Pivot Tables, Pivot Charts, formulas, data cleaning, and dashboards to convert raw sales data into meaningful business insights.

🎯 Objectives

Analyze overall supermarket sales performance.

Identify the best-performing products and product categories.

Understand sales trends over time.

Analyze customer purchasing patterns.

Compare sales across different branches or locations.

Identify high-performing payment methods.

Create an interactive and easy-to-understand Excel dashboard.
